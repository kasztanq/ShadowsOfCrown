How to Build a Dual-Game HTML5 Arcade Hub Step-by-Step

STEP 1 State Machine & Shared Game Loop Architecture

When combining multiple games into one HTML5 Canvas, the cleanest approach is a central state machine (`currentMode = 'MENU' | 'SNAKE' | 'SPACE'`). A single `requestAnimationFrame(masterLoop)` runs continuously and delegates rendering and physics updates to whichever cartridge is active, preventing duplicate loops or memory leaks when switching back and forth. 

let currentMode = 'MENU'; // 'MENU', 'SNAKE', or 'SPACE'

function masterLoop(timestamp) {
  const dt = timestamp - lastTime;
  lastTime = timestamp;

  if (!isPaused && !isGameOver) {
    if (currentMode === 'SNAKE') updateSnakeGame(timestamp);
    else if (currentMode === 'SPACE') updateSpaceGame(dt);
  }

  if (currentMode === 'SNAKE') drawSnakeGame();
  else if (currentMode === 'SPACE') drawSpaceGame();

  requestAnimationFrame(masterLoop);
}

STEP 2 Drawing Custom Vector Chestnuts on Canvas

Instead of relying on external image files that can fail to load offline, we use a reusable `drawChestnut(ctx, x, y, radius, angle, hasBurr)` function. It renders a spiky green husk (if enabled), a rich brown rounded-triangle shell, a creamy tan base (`#fde68a`), and a glossy white highlight arc. This same function draws the Snake food AND the spinning mini-chestnut bullets in Space Chestnut! 

function drawChestnut(ctx, x, y, radius, rotation = 0, showBurr = false) {
  ctx.save();
  ctx.translate(x, y);
  ctx.rotate(rotation);
  // 1. Optional Spiky Green Burr Halo
  // 2. Dark Brown Glossy Chestnut Dome (bezierCurveTo)
  // 3. Light Tan Hilum Base + Specular White Shine
  ctx.restore();
}

STEP 3 Game 1 Logic: Grid-Based "Chestnut Snake"

In Chestnut Snake, the 800×500 canvas is divided into a 25×25px grid (32 columns × 20 rows). We use an input queue (`snake.dirQueue`) so rapid key presses (e.g., Up then Left within a single tick) never cause accidental self-collision. Eating a chestnut spawns green burr spikes as particles and decreases `moveInterval` to speed up the game. 

// Move snake head on each tick interval
const head = { x: snake.body[0].x + snake.dir.x, y: snake.body[0].y + snake.dir.y };
snake.body.unshift(head); // Add new head

if (head.x === food.x && head.y === food.y) {
  score += food.isGolden ? 30 : 10;
  spawnBurrParticles(head.x * GRID_SIZE, head.y * GRID_SIZE);
  spawnSnakeFood(); // Don't pop tail -> Snake grows!
} else {
  snake.body.pop(); // Remove tail segment to keep length constant
}

STEP 4 Game 2 Logic: "Space Chestnut" (Nokia Space Impact Style)

In Space Chestnut, the player's Starfighter moves smoothly in 4 directions (`WASD` or `Arrows`) while pressing `SPACE` fires miniature spinning chestnuts (`bullet.angle += 0.25` per frame). Enemies spawn in waves with distinct behaviors:

  • Alien Acorn Bugs (1 HP): Fly in a smooth sine-wave (`Math.sin(frame * 0.06)`) pattern across space.
  • Space Squirrels (2 HP): Actively track the player's vertical `Y` position (`homing` behavior).
  • Spiky Burr Asteroids (3 HP): Heavy rotating hazards that split into green spine shrapnel when destroyed.
  • Giant Mecha-Squirrel Dreadnought (Boss Wave): Appears every 150 points with a multi-hit health bar and radial plasma projectiles!
