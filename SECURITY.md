# Security Policy

ShadowsOfCrown is a collection of static browser games and educational pages.
Security reports about the project code are welcome.

## Supported Versions

Security fixes are made to the latest version on the `main` branch. Older
revisions, copies, and forks are not maintained by this project.

| Version | Supported |
| ------- | --------- |
| Latest version on `main` | Yes |
| Older revisions and forks | No |

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through GitHub's **Report a
vulnerability** feature on this repository's **Security** tab. Do not disclose
the issue in a public issue, discussion, or pull request before a fix is
available.

If private vulnerability reporting is unavailable, contact the repository
maintainer privately through GitHub before sharing technical details publicly.

Include, where possible:

- The affected HTML page, file, or commit.
- The browser and operating system used.
- Steps to reproduce the issue and its potential security impact.
- Relevant screenshots or logs, with personal data and secrets removed.

Please do not access, alter, or delete anyone else's data while investigating
or demonstrating a potential issue.

## Project Scope

This repository contains client-side HTML, CSS, and JavaScript games. Game
progress and settings may be stored locally in the user's browser. A report is
in scope when it demonstrates a security impact in code maintained in this
repository, such as unsafe handling of untrusted input or unintended exposure
of sensitive information.

Visual issues, gameplay bugs, feature requests, and vulnerabilities in
third-party services are outside the scope of this policy. Some pages load
fonts, icons, or styles from external providers; please report issues with
those services to their respective maintainers.

## Response and Disclosure

The maintainer will review reports as soon as reasonably possible and may
contact the reporter for clarification. There is no guaranteed response or
resolution time. Please allow the maintainer a reasonable opportunity to
investigate and address a confirmed issue before publicly disclosing it.
